# 0.3.19 存档与采集改进

在 `fix/windows-vm-backup` 分支开发。退出游戏及旧版助手后，双击根目录的“启动晶石助手.cmd”启动本版本；原生桥接版本已升至 16，需要重新启动游戏才能加载。

- 存档操作、还原确认、删除确认固定在列表上方，仅备份列表滚动。存档、采集和设置窗口置顶。
- “保留一份手动备份”生成带 manual 的独立备份；“更新当前状态（latest）”生成当前状态快照并更新 latest。latest 可覆盖，不代表想保留的战斗前进度。还原前保险副本单独标记。旧版无来源记录的快照明确显示来源未标注；仍应按截图和游戏存档时间选择。
- 全选或多选后可删除所选备份：先勾选确认，再在第二个确认框核对。文件和校验文件移入回收站，不删除游戏存档；网络目录不支持此清理方式。
- 采集配置最上方增加食用蘑菇共享组，松乳菇、牛肝菌、鸡油菌、羊肚菌合计达到指定数量后停止采集，覆盖这四种的单独规则。毒伞菇、毒蝇伞不计入共享组。
- 小扁豆植株开启自动剥取后，行走途中也会处理已携带植株。此行保留量按剥出的豆籽计，与豆籽行取较高值，超量制饲料也遵守该保留量。
- 行旅栏增加自动采集开关，右击进入采集配置；图标按补给、采集与显示、移动、存档与配置排列。
- 物品常显扩展到原版容器名称的创建和保留检查，不用持续按 Alt；沿用游戏的可见性规则。

验证范围：原生模拟测试、托管离线测试、临时目录存档回归、无窗口的布局截图检查。未操作真实存档、未删除用户备份、未注入或操作正在运行的游戏。剥取、容器常显和游戏中置顶效果需要重启后实测。
