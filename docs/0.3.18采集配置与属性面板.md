# 0.3.18 开发版：采集配置与属性面板

开发分支：`fix/windows-vm-backup`。本次只做构建、模拟原版调用的离线测试和真实 WPF 组件的离屏预览，没有连接、操作或重启正在运行的游戏／助手。实机验收由玩家完成。

## 重启与入口

这次桥接升级到 v15。请在方便时 **游戏内保存 → 正常退出游戏 → 退出旧助手 → 双击根目录“启动晶石助手.cmd” → 重新打开游戏**。仅重启助手不能替换游戏里已经加载的 v14 组件，新版会提示重启游戏。

本地已隔离构建到 `artifacts/development/0.3.18/app/`，没有覆盖正在加载的旧 DLL；根目录启动器优先选择这个开发版。新克隆的仓库没有这个目录时，启动器仍使用常规 Release 构建。

右键主面板“饲料”按钮，或进入设置中的饲料入口，打开采集配置表。

## 配置含义

| 列 | 行为 |
| --- | --- |
| 采集物品 | 未勾选时，不自动采集或自动转换此物品 |
| 背包 | 新鲜完整数据下的物品件数／原版堆叠数；不是食用次数。不完整时显示 — |
| 最低保留 | 0–999；输入后按回车或移开焦点保存 |
| 超量转饲料 | 持续采集；只消耗超出保留线的整件或整堆。不支持原版饲料配方的物品不可勾选 |
| 自动剥取 | 当前适配小扁豆植株：先保留植株，剩余植株优先调用原版“剥取”动作生成豆籽；豆籽独立设置保留量和超量转换 |

数量按原版 `can_stack/stack` 计数，非堆叠物品按一件计数。不会修改堆叠上限、材料产值、回合成本或生成物品。整堆转换会穿过保留线时，整堆都留下，所以最终库存可以多于最低数量。原版一次采集也可能取得多件。

剥取时，如果豆籽已达到保留量，且未启用豆籽超量转饲料，不再为了剥取继续绕路采植株。若还要补齐植株本身的保留量，仍会补齐植株。勾选剥取后，不会把植株抢先做成饲料。

默认保留数量为 5；沿用原先浆果和常见药草的采集选项，超量转饲料和自动剥取默认关闭。自动采集总开关保留原来的设置。

| 示例物品 | 采集 | 保留 | 超量转饲料 | 剥取 |
| --- | --- | ---: | --- | --- |
| 羊肚菌 | 勾选 | 5 | 原版不支持 | 不支持 |
| 蓝莓 | 勾选 | 5 | 勾选后持续采集并处理多余部分 | 不支持 |
| 小扁豆植株 | 勾选 | 0 | 关闭 | 勾选 |
| 小扁豆籽 | 勾选 | 8 | 按需勾选 | 不支持 |
| 车前草 | 勾选 | 3 | 按需勾选 | 不支持 |

内置 32 种物品：7 种浆果、6 种蘑菇、小扁豆植株／豆籽与大黄、16 种药草。物品原生标识可悬停查看，背包数量悬停可看到游戏实时名称。

保留手动制作的独立折叠区，标题明确标注它会消耗手动勾选材料的全部可用数量；自动采集表的保留线用于自动处理。

## 属性面板

- 移除分类下拉框，直接显示分组；保留“全部／特别关注”。
- 滚动条、按钮、提示框与配置表使用深紫色主题。
- 拖动标题移动，拖动四角改变宽高；尺寸和位置保存。拉宽后按组分列，拉长可显示更多属性。
- 显示 `当前值（相对基线的增减）`；百分比属性的 `pp` 表示百分点。
- 只使用已确认的原生基线。未知基线显示 `（—）`，不会把第一次观测值当作角色基础值。
- 点击“设为基线”，用当前完整的新鲜属性作为本次对比基线，顶部状态显示记录时间。它包含记录当时的装备与状态，**不是无装备／无增益的角色基础属性**。换角色、数据失效或重启助手后清除。
- 悬停属性显示基线来源、当前差值和游戏可读取的修正来源。不能确认的乘算、取整及来源不会猜测。

## 开发与离线验证

```powershell
pwsh -NoProfile -File scripts/test-offline.ps1 -OutputRoot artifacts/development/0.3.18
dotnet build tools/FeaturePreview/FeaturePreview.csproj -c Release --artifacts-path artifacts/preview-build -o artifacts/feature-preview-host
dotnet artifacts/feature-preview-host/StoneshardCompanion.dll artifacts/development/0.3.18/previews
```

离屏工具使用正式视图源码和独立的无行为协调器，不显示窗口、不加载真实助手、不读取个人设置或存档，也不连接游戏。预览图是演示数据。

静态核对：物品标识与饲料资格来自本机受支持版本的 `consum_stat_data`；剥取沿用 `scr_create_context_menu` 的 `Flay` 动作与原生上下文按钮 Mouse_4 处理器。源码与该版本的 EXE 哈希校验绑定。

仍待玩家验证：真实行走中的蘑菇采集、豆荚剥取的容量与产物、超量制作、重新上路、战斗／手动接管停止，以及实际游戏窗口中不同 DPI 下的拖动与缩放。离线模拟通过不等于这些场景已实机通过。

本次验证结果：隔离构建 0 警告、0 错误；完整 `test-offline.ps1` 通过，新增保留线、剥取、配置编码和基线显示检查通过；另补充执行了剥取确认／拒绝的自动行走状态机检查。离屏预览覆盖 250×250、300×850、1000×390 属性内容区域及配置表中部滚动。原游戏和助手进程保持运行。
