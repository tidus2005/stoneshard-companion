# 0.3.23 存档状态更新

本机独立测试中，EXE 启动方式的测试进程在触发备份后无托管异常、无正常退出事件地结束；相同测试由已安装的 .NET 运行时执行则完成。尚未取得能确认系统终止来源的日志，不将原因归于特定安全软件。

变更：

- 手动备份和更新 latest 在后台线程执行既有 SaveEngine，不再重新启动 UI 程序作为备份子进程；保留并发门禁、锁定、校验和原有备份格式。还原仍使用独立工作进程。
- 开发版快捷方式和启动脚本采用已安装的 dotnet 运行助手 DLL。此运行模式不执行会复制／替换宿主程序的正式版自动更新。
- 窗口刷新和截图读取异常保留日志，不从事件回调直接传播；错误日志写入失败可退回临时目录，避免报错过程再次触发异常。

验证：真实 MainWindow/SaveWindow 按钮链路对临时目录连续执行三次 latest 更新，独立进程验证通过；8 项存档回归及 39 项存档兼容检查通过。未操作用户真实游戏存档。完整游戏环境下仍需用户启动新版确认。
