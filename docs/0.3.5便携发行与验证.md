# 0.3.5 Windows 11 x64 便携发行

GitHub Releases 提供 `StoneshardCompanion-0.3.5-win-x64.zip` 和同名 `.sha256` 校验文件。下载后完整解压，双击 `Start.cmd` 或 `StoneshardCompanion.exe`。无需自行编译、安装 .NET 或 PowerShell。

发行包保留 0.3.4 游戏功能，新增固定版本的官方 PowerShell 7.6.5 win-x64 便携运行组件。存档服务优先从自身随附脚本对应的 `Runtime/PowerShell/pwsh.exe` 启动，路径不依赖当前工作目录或 PATH。源码开发模式保留系统 PowerShell 7 回退。包内运行目录存在但主程序缺失时直接提示重新解压，不静默回退。

构建下载地址和官方 SHA256 固定在 `scripts/portable-runtime.json`，下载和缓存复用均先校验。官方 PowerShell 文件和许可证完整保留，运行组件不安装到 Windows。发行包仅包含助手及运行依赖，不含游戏、真实存档、本机配置、日志或开发工具。

## 验证

- `scripts/test-offline.ps1`：27 项原生补给、123 项原生交互、39 项倍率意图、63 项托管、8 项存档核心回归全部通过。
- `scripts/test-portable.ps1 -ZipPath <便携 ZIP>`：真实解压到带中文和空格的新目录，逐一检查包内 SHA256 清单。
- 便携检查使用自带 .NET 的测试程序，测试进程 PATH 仅保留 Windows System32。复用完整托管和存档服务测试，备份、最新副本、还原、损坏校验、路径越界和文件占用检查均通过，数据只写临时目录。
- 观察测试进程的 PowerShell 子进程，确认所有存档子进程均从解压包的 Runtime 目录启动，未使用本机 PowerShell 安装。
- 包含 668 个文件；外部 ZIP 校验文件用于下载完整性验证，内部 SHA256 清单覆盖除自身外的全部文件。
