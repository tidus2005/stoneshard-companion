## 已发现、修复并复测的问题

| 问题 | 原因和修改 | 实机复测 |
|---|---|---|
| 常显开启后原版点击异常，远距离行走被打断 | 游戏的 Alt 同时参与强制攻击，重新发送按下还会取消排队行走。原输入到达前先释放助手持有的虚拟 Alt，并清除它造成的缓存攻击模式；整个移动/动作期间让出输入，空闲约 600 ms 后恢复 | 背包操作、使用草药、短距离和 40 多格长距离行走成功；停止行走后标签恢复；连续走过 6 次地图边界 |
| 设置和存档窗口显示空白 | 本机 WPF 渲染异常；小型静态面板改用软件渲染 | 实际显示设置、滑块和备份历史；操作阈值、备份、退出按钮成功 |
| 快速拖动四角尺寸不变 | WPF 处理 DragStarted 时鼠标已到终点；起点错误，且可能没有中间 DragDelta | 从原始鼠标按下消息保存起点，在 DragCompleted 也应用最终位置；四个角和顶部逐个实际拖拽成功，重启后布局仍在 |
| 世界地图内仍保持加速和自动补给资格 | 全屏世界地图没有设置既有菜单的 mapActive 标志 | 根据真实 `o_globalmap` 实例添加阻塞标志。地图打开后实际倍率 1×、标签释放、补给资格关闭；关闭后恢复所选 2× 和常显。地图内喝水快捷键没有消耗物品 |

常显的“恢复”是保留用户选择并在适当状态恢复标签，点击和连续动作期间会短暂让出输入。手动按住的物理 Alt 仍由用户控制。

## 离线回归和交付

最终产品代码通过 `scripts/test-offline.ps1`：41 项原生补给/常显模拟检查、39 项倍率意图检查、43 项布局/策略/图形存档服务检查（含 500 个几何拖拽样例），以及原存档核心 8 项检查；构建为 0 警告、0 错误。

## 已知边界及尚未完成的实测

- 自动火把：角色没有随身火把，因此实际点亮、熄灭、燃尽后换备用、不同手部装备组合尚未验证。自动模式当前是持续保持点亮，不自动判断昼夜。
- 自动补给：真实敌人接近、战斗、受伤、缺水及特殊饮水容器组合尚未逐项覆盖；只有对应离线条件检查。
- 存档还原：本轮验证了真实图形备份及临时夹具的恢复/校验，没有对正式角色做热还原。原版“保存退出再继续”成功不等于“助手替换文件后游戏读档”成功。历史运行中热还原的加载失败仍保留为限制。
- 窗口：不同 DPI、多显示器、游戏窗口销毁重建、独占全屏以及数小时不间断游玩的稳定性尚未实测。
- 功能范围：上下左右及中央五点角色走图仍未实现；本轮测试的是原版行走和切图恢复，镜头居中仅改变视角。
- 测试操作工具的瞬间点击偶尔被原版帧轮询漏过；关闭助手的对照场景也出现。测试中以按钮范围内短拖动维持按下完成操作，没有把工具漏点误记为助手故障。
- 本机测试副本使用重定向的物理目录和该目录作为工作目录后正常启动；旧别名启动路径出现过 C++ Runtime Error，助手开启和关闭两组均可复现。该情况与产品修复后的游戏运行分别记录，不作为桥接已解决的崩溃问题。

已测试场景中没有遗留可复现的阻断问题。以上未覆盖项不作“全部场景稳定”的结论。
