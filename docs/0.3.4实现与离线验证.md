# 0.3.4 九宫格与方向键自动移动

本次实现九宫格地图目标，以及可开关的普通方向键自动移动。仅构建与离线测试，没有启动游戏、接管桌面、发送游戏输入或操作真实存档。以下通过项不能替代实机验收。

## 行为

左侧固定 108 × 108 的九宫格，从上至下为 `↖ ↑ ↗ / ← ◎ → / ↙ ↓ ↘`。四向保留 0.3.3 的一次相邻地图切换；四个斜向到地图内侧角点即停，中心键走到地图中心。行走中点击任一九宫格按钮停步，右侧镜头居中功能独立保留。

面板顶部新增“方向键自动移动”开关，始终显示开、关或待命，设置窗口也可修改。默认关闭，记住选择，切图及重连后同步。开启后轻按普通方向键，上下沿人物所在列、左右沿人物所在行寻路到内侧边缘后停止；保持原版移动及回合消耗，地形可使路线绕行。再次轻按方向键停步，长按不会重复发起路线。关闭开关停止键盘路线；九宫格独立路线不受该开关影响。总停止关闭此模式及所有行走。

键盘处理仅挂在游戏窗口消息回调，不注册全局无修饰方向键。Ctrl、Alt、Shift、Win 组合保留原操作。后台、失联、场景未就绪、面板和对话均不发起助手行走；悬停说明不阻断。遇敌、受伤、手动接管、场景变化和长时间无进展后停止，无攻击调用、重试或连续跨图。

## 实现

- 原生方向编号 1–5 保留，6–9 为左上、右上、左下、右下，11–14 为人物相对四方向；对外 Walk 命令仅接受 0–9，11–14 由窗口内方向键处理调用。
- 相对目标以当前地图中人物所在格子的中心坐标计算，忽略镜头偏移。地图、人物坐标非法或目标落在切图外圈时拒绝相对行走。
- WM_KEYDOWN 的 previous-key-state 位用于排除长按重复，包括到达、遇敌、切图和取消后仍按着键的情况。第二次独立按下先停止已有路线，不自动替换或重试。
- 桥接 ABI 升至 v6：映射 `Local\StoneshardCompanion.v6.<pid>`，状态大小仍为 3968，3964 原尾部填充位置发布键盘开关。原偏移保持，旧版桥接被拒绝混用。升级时应正常重启游戏以载入新 DLL。
- 复用现有单路线监督器，只有四向九宫格路线允许第二阶段出口点击；中心、角点、人物相对路线均在到达时结束。

## 离线验证

运行 `pwsh -NoProfile -File scripts/test-offline.ps1`：构建无警告、无错误；27 项原生补给、123 项原生交互、39 项速度意图、63 项托管检查和 8 项存档核心回归通过。

新增覆盖四角坐标与到达即停、矩形地图、四个人物相对目标、非法人物坐标、已经到边缘、禁用/失联/后台/面板、修饰键、全部四个普通方向键、长按不重复、再次按下停步、敌人/伤害/受伤、关闭开关、切图不续走，以及 ABI 解码与目标文案。原生模拟只允许调用原版移动与停止脚本，其他脚本调用会令测试失败。存档测试仅使用临时数据。

发布入口为根目录 `启动晶石助手.cmd`，指向独立的 `artifacts/release/StoneshardCompanion-0.3.4/`，旧版成品保留。发布内容包含 EXE、DLL、Assets、使用说明、授权和 SHA256 清单，另生成完整 ZIP。

尚待实机验收：GameMaker 对普通方向键的实际消费行为、不同地图及障碍下的角点/边缘寻路、焦点与原版 UI 切换，以及实际窗口尺寸下的视觉效果。既有 0.3.3 自动跨图和自动火把未实测项仍不视为已验证。
