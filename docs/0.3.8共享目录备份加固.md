# 0.3.8 共享目录备份加固

在 0.3.7 移除 PowerShell 依赖之后，继续优化 Windows 本地磁盘、虚拟机共享目录和网络路径之间的存档操作。

## 本地准备，再向目标传输

快照、压缩、解压核对在 `%LOCALAPPDATA%\StoneshardCompanion\BackupRecovery` 的独立临时子目录中完成。共享盘不再承受大量小文件快照读写，仅接收生成完成的 ZIP。复制使用字节流，不继承源文件的 ACL 或文件属性；写入完成刷新并核对 SHA256。

目标端先写临时文件，校验后再发布历史备份。复制/校验/发布失败，已经生成并校验的本地 ZIP 和 `.sha256` 保留，界面提示具体路径。“本地备用备份”按钮打开该目录，用户可在目标恢复后复制两份文件。未完成的上传不会作为历史备份列出。失败后不立即再次访问目标盘清理，以免断线盘让错误反馈继续等待；目标可能留下不进入列表的 `.work-*` 临时目录。最初连接或锁定目标目录失败时，尚未开始生成本地备份，不会声称已有备用副本。

刷新最新备份前检查原 ZIP 和校验文件的占用/只读状态；历史备份独立保留。不能将“两文件更新”承诺为网络断电下的原子事务：发布过程中突然断网仍可能留下不匹配的最新副本，校验会拒绝还原，用户可使用独立历史备份或本地保留副本。

## 列表与路径

历史列表在后台读取，保留旧列表直到新结果返回；存档进度仅更新状态，不反复枚举目录。同一窗口只保留一个正在读取的任务，后续刷新合并；目录切换后丢弃旧目录的结果。共享路径读取失败显示错误，不当成“尚无备份”。

修正盘符根目录的包含关系判断，禁止把包含存档的整个磁盘根目录选为备份目录；禁止将本地工作目录放进存档中。原目录选择、中文/特殊字符/长路径兼容、旧 ZIP 兼容和还原保护保持有效。

## 验证与限制

离线检查共 362 项（原 353 项加 9 项）：新增传输失败故障注入、验证本地副本及仅保留 ZIP/校验文件、拒绝发布半成品、最新校验文件占用、存档不被传输故障修改、盘符根目录隔离和后台列表结果检查。

发行流程对实际解压后的自带 .NET 程序再执行备份与还原检查，保留无 PowerShell、特殊字符路径验证。测试仅使用临时存档，不操作游戏或个人存档。Windows 网络共享路径与真实 Mac 虚拟机共享驱动不是同一环境，后者仍需对应环境实测。

新增可重复执行的共享目录测试脚本 `scripts/test-shared-save.ps1`（开发验证需 PowerShell 7），传入解压的发行目录和已有可写 UNC 目录；脚本不会创建共享或修改系统设置。它把测试程序放在共享路径运行，同时向共享目录备份并还原临时存档，结束后仅清理本次创建的目录。本机 Windows SMB 环回共享测试已通过。

```powershell
pwsh -File scripts/test-shared-save.ps1 -PackageFolder artifacts/release/StoneshardCompanion-0.3.8 -ShareRoot '\\server\share\existing-test-folder'
```
