# v0.3.14

- 修复向上切图点到人物头部：向上出口点击提高 10 个游戏坐标单位；抵达出口后的避让等待从 600 ms 缩短至 120 ms，鼠标移动等待和按键保持分别缩短至 70 ms。修复原版寻路在格子间短暂空闲时被误判为受阻。
- 修复一键制作饲料闪退：使用原版制作面板作为配方上下文，通过原版背包容器解析与放置函数转移材料及产物。只消耗勾选种类，空间不足时材料留在原版制作面板中，按 Escape 关闭面板。
- 行旅辅助顶部增加明确的“设置”入口；属性面板默认缩至 290 × 380。两个浮窗可分别调整背景不透明度、开关边框，属性面板可调整宽高和字号，设置即时生效并保存，文字保持清晰。
- 存档列表旁显示备份内最近一次游戏原生存档截图，优先当前角色，显示存档时间与槽位；截图时间可能早于备份时间。
- 行旅辅助显示食物、水的预计可支撑游戏小时／天数，以饥饿、口渴 25% 为补给界限。根据行走期间游戏时间和需求增长估算消耗，也可在设置中手动指定每小时消耗。统计随身数量、回复量与食物保鲜时间；无法读取回复量的食物不计入，悬停可查看明细与估算限制。
- 装备耐久达到预警线显示黄色，损坏显示红色；悬停查看各件装备的名称、耐久和百分比，预警线可调。
- 修正疲劳等属性读取源和属性键，增加已核对的基础属性贡献规则。兵器伤害显示 100% 基准、力量贡献及其余净变化；实时列出游戏记录的装备／技能／状态来源。未知基线及未能还原的乘算关系会明确说明，不把原始来源重复相加。

## 验证范围

在 Mac 的 Windows ARM64 虚拟机中，使用 x64 兼容运行和原版 Stoneshard 0.9.4.25 / Build 24780451，实际验证了四方向自动切图、连续整行寻路、蓝莓转成 3 份饲料且未勾选胡萝卜保留、喝水及进食后数量和属性变化、消耗率采样、黄色装备预警、游戏内设置、透明度／边框／宽度／字号、属性分类与星标关注、说明浮层、备份截图和完全退出助手。

损坏红色分支、背包满等异常路径通过模拟回归；没有为测试故意损坏角色装备。续航为近似规划值，天气、盐分、战斗与后续状态会改变消耗，尚未实测所有食物。基础属性贡献规则覆盖已核对的 10～30 点范围，尚不能完整还原所有技能、伤势与敌方效果的最终公式。不同 DPI、多种地图障碍和全部战斗场景仍需扩大覆盖。

桥接协议升级至 v11。请正常退出游戏后更新；自动更新会等待游戏关闭，再安装并重启助手。不能在已加载旧桥接的游戏进程中热替换。
