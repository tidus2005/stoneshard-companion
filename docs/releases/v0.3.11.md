# 0.3.11：退出按钮、浮层层级与自动更新

- 主面板右上角常驻“退出助手”，底部显示版本号；设置和存档窗口标题统一显示版本。存档操作中请求退出，会等待该操作完成后自动退出。
- 设置、存档窗口设为助手的所属置顶窗口。面板定时定位不再改变窗口层级，避免盖住设置、目录选择、右键菜单和提示。
- 默认启动时检查 GitHub 最新正式版，运行期间每六小时检查一次；设置页可关闭自动更新，也可点击“检查更新”。只升级，不降级，不安装预发布版。
- 下载当前仓库的 Windows x64 ZIP 和 SHA256 文件，校验下载长度、ZIP 哈希、内部文件清单及程序版本。游戏运行或存档操作中只准备更新；空闲后由独立更新组件等待旧进程退出、替换文件并重启。
- 替换前保留旧文件；失败时回退，回退不完整则保留材料并明确提示，不启动混合版本。共享驱动短暂占用文件时有限重试。更新材料位于 Windows 本地应用数据目录的 `StoneshardCompanion/Updates`。

首次需手动解压这一版本，以后由其内置更新器跟随本仓库正式发布。开发运行环境只检测，不覆盖开发目录。离线、GitHub 限流和目录权限错误会显示在设置页，不影响当前版本继续使用。

验证使用独立临时文件和 UI 测试配置，不启动游戏、不修改个人存档或正在使用的旧助手。已检查窄面板显示、点击退出后进程结束、设置与存档浮层、目录选择以及真实 GitHub 版本查询。更新包校验、文件替换和失败回退有离线回归检查；未将测试版本发布到 GitHub，因此不把本地更新交接测试称为线上跨版本升级验收。

新增 14 项更新回归通过；打包后的真实更新组件已在独立测试程序上通过就绪握手、旧进程退出、全部文件替换及哈希验证、保留回退副本和自动重启验证。发布工作流加入同样的更新组件检查。
