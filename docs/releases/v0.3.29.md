# v0.3.29 — 助手内属性与技能编辑

在助手设置首页和行旅辅助的“加点编辑”中打开独立窗口。左侧调整五项属性，右侧按技能类别、中文搜索、只看已选筛选；使用本机游戏图标与中文说明，未打包游戏素材。减号返还点数，加号重新分配，底部显示完整差异、剩余点数与克朗；撤销或未修改不收费。

一次确认扣除随身 500 克朗，不从马车或其他容器取钱。属性不能低于角色初始值或高于 30，属性点与技能点分别守恒。技能允许按点数自由重配，当前不模拟原版技能树的前置要求；免费基础动作不可退点。移除技能会清除相应快捷栏和可确认来源的临时状态，新主动技能在游戏内重新拖入快捷栏。等级、经验、书籍记录和非金币物品保持原值。

确认写入前必须正常保存并退出游戏，然后刷新。编辑最后使用的有效槽位，先生成完整保险备份，再校验源文件未变并写入；游戏运行、无效槽位、余额不足、重复提交、存档变化或备份失败都会拒绝写入。修改后从原版 Load 加载同一槽位，存档列表仍显示该次游戏保存的时间与截图。

实机验收发现默认 .NET JSON 编码会将嵌套地图字符串的引号改成 Unicode 转义，导致游戏 JSON 解析失败。已调整公共保存编码器，保留原生 UTF-8 与转义引号；这项修复也用于原有的 2000 克朗全部重置功能。
