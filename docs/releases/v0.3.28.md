# v0.3.28 — 立即存档（本地待实测）

行旅辅助首页和设置页新增“立即存档”。不需要睡觉，调用当前受支持游戏版本 0.9.4.25 的原生自动存档流程。读取时仍在游戏原生 Load 界面选择该角色的自动存档。自动存档槽位按游戏规则轮换；助手会额外保留保存前后的 ZIP 备份。

使用前先停步，关闭原版菜单，等待回合和场景加载完成。人物死亡、加载中、自动行走/采集中及不支持的游戏版本不发起保存。不以请求回执作为成功：需要原生索引指向自动存档、数据和信息文件通过校验、截图存在且文件连续两次读取稳定才显示成功。超时或失败不自动重发。额外备份失败会与游戏存档成功分开报告。

桥接协议更新为 20。使用新版前退出游戏和旧助手，再运行项目根目录“启动晶石助手.cmd”；旧桥接不能在同一游戏进程中热替换。没有修改当前真实存档。

## 验证范围

静态核对：原生 `o_autosave_trigger` Step 以零参数调用 `scr_smoothSaveAuto`（RVA 0xb55530）；其队列执行原生场景保存及 `scr_savegame`，准备原生标题与截图。没有调用睡眠或退出入口。

自动测试：原生调用 ABI/状态保护、文件校验、未变化存档、角色切换、不完整文件、无效元数据、重复点击、请求失败、超时，以及保存前后备份流程。只使用临时存档与模拟原生调用，不代表游戏内实测。

游戏内 Save → 原版 Load 回读尚未完成：Codex JavaScript/界面工具初始化报 `failed to write kernel assets: 系统找不到指定的路径。 (os error 3)`。本版本尚未发布 GitHub Release，不宣称已通过实机验收。
