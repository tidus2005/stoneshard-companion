# v0.3.26（本地开发版）

- 采集后取消残留移动，原地等待两个物资对象族完整扫描，再从上一件物资附近选下一件；目标不可达、超时或消失也先扫描其他目标。附近没有候选物资时才恢复原始目的地；扫描超时安全停止。
- 首页增加“收纳：开/关”。启用后，打开 I 及已装备的背包，停手 1.2 秒会整理主物品栏里的战利品。按当前基础价值优先处理；先尝试小隔袋，再尝试大格区，最终由原版放置规则决定是否兼容与能否容纳。
- 食物、水、医疗用品、药品、任务物品、已装备物品、容器及分类不明物品保留。放不下的留在原处；不会向地面丢弃或转移到地面箱子。原版背包开启仍由玩家操作，未实现关闭背包时的后台收纳。
- 手动操作、战斗、移动、后台和其他菜单暂停收纳；原版转移返回成功但归属未确认时停止后续操作。状态见首页收纳按钮的提示。
- 原生桥协议升至 19。旧桥不能热替换；如游戏尚在运行，需要正常退出游戏并重开，助手也需重启。

## 验证范围

自动采集状态机、密集目标连续采集、扫描批次与路线恢复，以及收纳排序、小隔袋失败回退、满包、保护物品、错误容器与暂停条件使用模拟原生接口回归。构建与现有离线测试见 `artifacts/test-v0326.log`。这不等于游戏内实测：实际装备背包的容器字段与分袋转移仍需在真实存档中确认，当前版本默认关闭自动收纳。
