# v0.3.30 — 游戏运行时逐点退回

此前的加点编辑器要求退出游戏后修改存档。现在助手设置中的「逐点退回」读取游戏当前角色，属性和技能旁点击减号、确认后立即返还一点到原版点池；使用原版 C / S 重新分配。保留等级与经验，禁止退回角色初始属性及免费基础动作。

属性点每点 250 克朗，技能每点 500 克朗。这是助手自定义的平衡费用，不是官方洗点价格；小幅调整按点付费，完整重练累积成本。金币不足、角色状态变化、战斗或冷却未结束时拒绝执行。

技能前置关系直接读取原版技能树，包括 AND / OR 分支。已学后续技能仍依赖某个前置时，界面提示先退回后续技能，原生组件再次校验。德温生存树的种族赠点尚未完成逆向验证，暂不开放退回。

每次退点先调用原版保存并制作完整保险备份，再检查角色、金币与点数，使用原版支付逻辑扣款、返还点数、清理对应快捷栏并刷新属性。完成后再次保存并核对落盘数据。发生提交后异常时显示保险备份位置，避免重复扣款。

界面沿用本机游戏图标和技能中文名称，提供类别、已学筛选、搜索和依赖说明。已退回技能保留学习知识，可以立即从原版技能界面再次学习。旧桥接组件已载入时，升级需要正常重启游戏一次，之后退点无需退出。
