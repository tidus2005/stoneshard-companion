# 0.3.15 本地开发与实机验证

2026-09-10，Mac 上的 Windows ARM64 虚拟机，Steam Stoneshard 0.9.4.25 / Build 24780451。分支 fix/windows-vm-backup，原生桥接协议 v12。

## 功能

- 两个普通方向键同时按下，支持西北、东北、西南、东南自动路线，到先抵达的边缘后跨一张地图。150 毫秒组合窗口、按键松开与长按去重；遇敌和手动接管停止。
- 两个中心按钮均执行人物寻路。中心阻塞时从北开始，沿顺时针扩大的方环查找空闲可达格；每帧限制扫描量和时间。修正原版寻路查询需要格坐标却传入像素坐标的问题。
- 从主背包学习可制作饲料的材料名称，保存勾选；用完和重启后保留。沿途自动采集勾选药草、浆果，再调用原版配方制作、收回产物、关闭本次创建的制作面板，恢复原目标。
- 采集偏离路线先停止旧路径，等待原版处理取消后再发起新路径；制作完成后等待收尾，防止续走被原版事件打断。真实点击前让浮层让位，输入结束、前台、敌情、背包容量等守卫仍生效。
- 手动面罩旁新增自动开关；原版敌情或受击时关闭，连续安全 1.5 秒后打开，遵循原版回合限制。手动开合关闭自动模式。
