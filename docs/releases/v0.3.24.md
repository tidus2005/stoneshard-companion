# v0.3.24 — 快速备份、采集配置与属性面板

本版汇总 0.3.18–0.3.24 的开发改动，适配 Windows x64、Steam Stoneshard 0.9.4.25 / Build 24780451，原生桥接版本为 18。

## 更新内容

- 行旅面板增加快速备份与快速读档。读档固定使用明确的手动备份，先展示目标并要求确认；latest 和还原前保险不替换目标，目标缺失不自动回退。
- 存档操作与确认区固定在列表上方，区分手动、当前状态与保险备份；备份清理经确认后移入回收站。备份改为后台执行，补充异常日志与启动诊断。
- 采集配置支持逐项启用、保留量、超量转饲料和小扁豆剥取，增加食用蘑菇共享组、鸟蛋及数量增减按钮。默认保留量为 0，旧配置仅迁移归零一次。
- 打开背包并停止输入后，自动采集可处理确切匹配的腐烂浆果及已启用剥取的小扁豆植株。每次执行一次原版动作并确认结果；拒绝或结果不明时暂停。
- 属性面板支持分组、自定义基线、窗口缩放及变化着色；根据属性含义区分改善和变差，未知来源与过期数据不作推断。
- 配置统一存放于探测到的游戏目录，保留旧配置并避免覆盖已有共享配置；完善设置窗口与面板主题。
- 纳入离屏预览和真实存档窗口的隔离回归工具。

## 升级

先在游戏内保存并正常退出游戏，再退出旧助手，完整解压新版并运行 `Start.cmd`。仅重启助手无法替换游戏中已加载的旧桥接。

下载 `StoneshardCompanion-0.3.24-win-x64.zip`，无需另外安装 .NET 或 PowerShell。源码下载不包含构建产物。发行包不含游戏、个人存档或本机设置。

## 验证范围

发行前执行完整原生模拟与托管离线回归、临时目录存档检查、便携包哈希与独立存档工作进程检查，以及更新工作进程检查。GitHub Actions 重新构建并执行相同发行检查后才发布 ZIP 和 SHA256 文件。

新增采集、剥取、背包清理、窗口置顶及真实游戏读档行为仍待实机验收；离线通过不代表真实游戏或 Mac 虚拟机已通过。本次发布不启动游戏、不还原个人存档。
