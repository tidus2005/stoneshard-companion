# v0.3.31 — 宝石与契约历练退点

## 正式发布与升级（2026-09-25）

本次正式发布汇总 v0.3.24 之后的本地开发成果：连续采集时原地扫描并衔接邻近目标、首页采集开关、可选背包战利品收纳、立即调用原版存档，以及下述宝石退点机制。自动收纳默认关闭，需要打开 I 和已装备背包后使用；食物、水、医疗及任务物品保留在主物品栏。

在旧助手中检查更新即可下载本版本。请先正常保存并退出游戏，再更新并重启助手和游戏；原生桥接协议已升至 22，旧游戏进程不能热替换组件。支持的游戏版本仍为 Stoneshard 0.9.4.25。

发布包为 Windows x64 自包含 ZIP，不需要另装 .NET 或 PowerShell。仅发布助手程序与校验文件，不包含个人存档、测试备份或游戏素材。换电脑时游戏存档需要另外同步，助手在线更新不会迁移游戏进度。代码合并到 main，后续发布从 main 构建。

助手设置中的「逐点退回」改为消耗宝石和历练机会，不再扣金币。每次退回一个已投入的属性点或技能点，再在游戏原版 C / S 界面重新分配。等级、经验和总点数保持不变。

## 配方

| 退回点数 | 可选材料，每行任选一种 |
| --- | --- |
| 1 属性点 | 翡翠 ×2 ＋ 黄玉 ×1；或红宝石 ×1；或祖母绿 ×1 |
| 1 技能点 | 紫水晶 ×2 ＋ 海蓝宝石 ×2；或蓝宝石 ×1 ＋ 紫水晶 ×1 |
| 1 属性点或技能点 | 钻石 ×1 |

每笔还消耗 1 次历练机会。首次启用获得 2 次；此后每成功交付 1 个契约获得 2 次，上限 6 次，满额时溢出不累积。不追溯首次启用之前的契约。机会和已结算契约数写入角色存档，随存档一起保存、恢复，不因重开助手而重复赠送。

只使用 I 主背包中的独立宝石。镶在首饰上的宝石不计入；装备背包、马车仓库中的材料需要先取出。材料选择窗口显示持有量、所需量和缺少量；最终确认列明消耗，取消不会提交交易。

## 使用条件

- 回到城镇或马车营地，停步、离开战斗，等待技能冷却，关闭游戏菜单和悬停提示。
- 属性不能退到角色初始值以下；对正在维持已学技能解锁属性门槛的点数，保守阻止退回。读书解锁等替代条件暂未完整区分。
- 技能依据游戏运行时的 AND / OR 依赖图退回，不能跳过仍需要的前置。免费基础动作不可退回；德温涉及额外属性赠点的生存树继续暂不开放。
- 修改前原版保存并制作完整保险备份，核对状态未变化后消耗材料、退点，完成后再次原版保存，核对材料、历练、点数和技能。等待原版保存界面收起，避免保存完成时的短暂界面阻拦。
- 提交后出现异常会显示保险备份位置并要求停止重试，不声称能在游戏进程异常时自动回滚。

这是助手自定义的平衡规则，不是官方洗点机制。当前原生组件针对 Stoneshard 0.9.4.25；升级已载入的旧组件需要重启游戏一次，之后退点无需退出游戏。
