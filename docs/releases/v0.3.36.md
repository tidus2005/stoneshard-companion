# v0.3.36：稳定性修复、快捷存档与出发清单

本轮根据 B 站评论反馈，优先处理运行稳定性、模组连接提示和保存入口。保持原版探索、物品消耗、回合和风险，不新增免费资源或隐藏地图信息。

## 修复与改进

- 桥接升级为 v26：游戏正在执行原生脚本时，延后窗口回调中的命令和采样；退出回调时恢复脚本上下文，降低重入干扰游戏脚本的风险。保留命令序号、超时和场景核验。
- 移除重复战斗采样，补齐临时对象释放。
- 模组连接失败时区分 VM/modbranch 与文件指纹不匹配；可复制连接诊断和反馈模板。未知版本仍拒绝连接，存档管理可独立使用。**本版没有实现通用模组兼容。**
- 新增 `Ctrl+Alt+F5` 立即保存当前进度，托盘、设置和面板均有入口；完成后显示原版 Load 中的自动存档槽位。`Ctrl+Alt+B` 仍只备份已落盘进度。
- 新增可编辑“出发清单”：保存清单文字，每次打开重新勾选，提醒检查补给、耐久和进度；不自动补货或生成物品。
- 源码启动脚本跟随项目版本，避免误启旧构建。

## 验证与边界

- 全套离线回归、便携包和更新流程检查通过，新增 8 项脚本上下文检查与 18 项数据包兼容检查。
- 独立角色副本在营地持续采样 360.2 秒，完成 687 次刷新；短途原版走图、原版保存和 Load 读回通过。
- 实际按下存档快捷键，完整验证“前置备份→原版保存→落盘核验→后置备份→成功提示”。连续备份原路径复测通过，个人存档 65 个文件前后 SHA256 一致。
- 测试期间曾遇到连续备份进程提前退出；用户自行改变安全软件运行环境后，同一路径复测恢复正常。没有证实具体拦截规则，未更改备份保护逻辑，详见[验证记录](https://github.com/tidus2005/stoneshard-companion/blob/main/docs/验证记录-2026-10-16.md)。
- 评论中的 Steam Rich Presence 致命报错尚未在反馈者环境复现，不能宣称已彻底解决。营地测试不代表全部地形、长途或模组组合；战斗预览和超过 30 级后的行为仍保留原有实验性边界。

## 下载与升级

下载本页 Assets 中的 `StoneshardCompanion-0.3.36-win-x64.zip`，完整解压后运行 `Start.cmd`。自带运行时，无需另装 .NET 或 PowerShell。适配 Windows 10/11 x64、Steam Stoneshard 0.9.4.25 / Build 24780451。

**先保存进度、正常退出游戏和旧助手，再启动新版与游戏。** 已加载 v25 的游戏进程不能热换 v26，仅重启助手不够。不要覆盖或迁移个人存档来完成助手升级。
