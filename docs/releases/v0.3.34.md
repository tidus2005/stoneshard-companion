# 0.3.34 本地版：解除角色 30 级封顶

适用本机 Stoneshard 0.9.4.25 / Steam Build 24780451。

- 游戏升级与经验条两个 `LVL == 30` 判断改用不可达的负等级哨兵，仅两条指令中的 4 个字节变化。保留原版经验需求、升级、点数发放和保存流程；未设新的游戏等级上限。
- 助手仅接受原版和这一确定补丁的完整 SHA256，不放宽其他游戏版本的校验。高等级存档的退点、洗点读取兼容同步更新；基础属性上限仍为原版 30。
- 本地入口 `启动晶石助手.cmd` 使用 `artifacts/development/0.3.34/app`。

## 本机安装与备份

应用补丁前须正常退出游戏，并指定新的备份目录，例如 `$env:USERPROFILE\Documents\Stoneshard Save Backups\LevelUncap-<时间戳>`。脚本要求原版文件完整 SHA256 匹配。

其中 `StoneShard.exe` 是原版，`saves` 是真实 Windows 存档目录的完整副本，`manifest.json` 记录每个存档的哈希。个人存档没有被修改。

安装后游戏 SHA256：`2154985DEAB44A615C333173FACC10335D4328E6D1FE90C08AAFD82255BD71EC`。

本补丁直接安装在游戏 EXE，正常从 Steam 启动即可，不依赖助手运行。Steam 更新或校验游戏文件可能还原 EXE，需要重新核实版本后应用；旧助手会拒绝连接修改后的 EXE，请使用 0.3.34。

## 检查与撤回

在项目目录执行（Python 3）：

```powershell
python scripts/level-cap.py check --game 'D:\Program Files (x86)\Steam\steamapps\common\Stoneshard\StoneShard.exe'
```

撤回前正常退出游戏。以下命令验证当前 EXE 确为此补丁，备份当前 EXE 后恢复原版，不改存档；备份目录必须尚不存在：

```powershell
python scripts/level-cap.py restore --game 'D:\Program Files (x86)\Steam\steamapps\common\Stoneshard\StoneShard.exe' --backup ((Join-Path $env:USERPROFILE 'Documents\Stoneshard Save Backups\LevelUncap-Restore-') + (Get-Date -Format 'yyyyMMdd-HHmmss'))
```

恢复 EXE 不会把已超过 30 级的存档降级。若需要回到修改前的角色状态，应另外恢复上述 `saves` 备份；不要在游戏运行时覆盖存档。
