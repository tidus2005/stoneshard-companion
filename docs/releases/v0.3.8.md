Windows 11 x64 免安装版。下载 `StoneshardCompanion-0.3.8-win-x64.zip`，完整解压到新目录，退出旧助手后双击 **Start.cmd**。

## 备份兼容性改进

- 本地生成并校验 ZIP 后才向目标目录传输，减少 Mac 虚拟机共享盘和网络目录的小文件读写。
- 传输失败时保留已校验的本地完整 ZIP 与 `.sha256`；新增 **本地备用备份** 入口。目标目录最初无法访问时会直接报错，不会声称已生成副本。
- 目标端先临时写入、校验后再发布，防止半成品进入历史列表；最新副本被占用时保留原文件，历史备份独立保存。
- 历史列表改为后台读取，进度更新不重复扫描目录；保留原列表，过滤目录切换后的过期结果。
- 修正盘符根目录包含判断，防止备份工作目录混入存档。

继续使用 0.3.7 的自带 .NET 存档引擎，**无需 PowerShell**；兼容旧备份、中文、特殊字符和长路径。游戏功能及 v7 桥接保持不变。

362 项离线检查及实际解压包验证通过。仅使用临时存档，未启动游戏或修改个人存档；未在用户的 Mac 虚拟机共享驱动中实测。仍为 Windows x64 包，非 macOS 原生应用。
