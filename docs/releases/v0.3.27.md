# v0.3.27 本地开发版

新增付费洗点：行旅辅助首页“洗点”或设置中的“2000 克朗：重置属性与技能加点”。

1. 在游戏中正常保存并退出到桌面。
2. 打开洗点窗口，刷新最后使用的退出存档，核对角色、等级、退点和余额。
3. 确认后先完整备份，再在同一次存档替换中扣除 2000 克朗并返还加点。
4. 重新进入游戏，继续退出存档并重新分配。

保留等级、经验、角色初始属性、基础动作、角色天赋、书籍／训练解锁、装备和任务。返还已分配属性点及已学的非基础技能点，加到现有未分配点数上。清理被移除技能的快捷栏及可识别的技能来源状态。只从主物品栏中的钱袋和散钱扣款；马车、地上箱子等不参与付款。无加点可返还、余额不足、校验不符、游戏运行或预览过期均拒绝执行。重复提交相同预览不能再次扣款。

当前核实的初始角色为 Arna、Jorgrim、Dirwin、Jonna、Velmir；其他角色暂时拒绝操作。角色初始数值参照游戏现有新角色存档及官方 wiki 的角色条目。存档封装遵循 zlib / JSON / 带路径盐的 MD5 / 结尾零字节，并先验证现有存档校验。

## 验证

`RespecTest` 在临时存档上验证退点守恒、基础动作、技能栏、状态来源、精确扣款、保险备份、重复提交、过期预览、低余额、无效校验、备份失败、未知角色和散钱用尽。真实角色只读取预览；另对其独立副本执行完整洗点与备份，确认保留 22 级及刚补回的长枪比武盔甲，余额 1786、可分配属性点 22、技能点 23。真实存档未执行洗点扣款；真实游戏加载后的界面效果未验证。
