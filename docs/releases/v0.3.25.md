# v0.3.25 — 连续采集与首页开关

本地开发版，2026-09-17。基于 v0.3.24，原生桥接协议仍为 18。

- 走向采集目标、等待原生回合及制作期间也持续发现当前视野内符合配置的物资。每次发现仍采用原有分批预算，不读取迷雾内物资来寻路。
- 采集制作结束后，从刚才物资的位置优先选择下一个可见目标，连续采集，不在每两株之间重新派发行旅路线。采集过程中保留最初的行旅终点；附近没有合适目标时完成一次有时限的分批搜索，再恢复原路线。
- 仍逐次使用原版采集、剥取、制作与堆叠，遵守类别选择、保留量、空间和回合限制；不改变原有摄像机稳定和制作完成等待。遇敌、失焦、菜单、手动接管和关闭采集仍停止。
- 首页自动采集按钮移到功能区第一位，始终显示“采集：开/关”，窄面板不再隐藏文字。左键直接切换，开启时有底色；右键仅用于材料配置。点击后返回游戏焦点。

构建目录：`artifacts/development/0.3.25/app`。根目录 `启动晶石助手.cmd` 和 `scripts/start-companion.ps1` 优先启动此构建；保留本机 .tools/dotnet 运行时兼容。
