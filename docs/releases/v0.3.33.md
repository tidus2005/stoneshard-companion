# v0.3.33 — 退点核验与异常保护

本地开发版，尚未发布到 GitHub。适配 Stoneshard 0.9.4.25 / Build 24780451。

此前退点先删除宝石，再写入点数。如果后续写入异常，只能报错并提示恢复保险备份。本版改为在同一游戏事件线程先修改并逐项核对属性、未分配点数和技能学习状态，再消耗宝石和历练。点数核验失败会尝试撤回，核验通过前不扣材料；无法核实撤回或扣费最终结果时，原生组件锁定后续退点。

每次提交前持久化本次请求、点数快照和保险备份位置。提交后失去响应或保存核验失败，会保留待核验记录，在同一次游戏进程内阻止重新提交，关闭并重新打开助手也不会清除。游戏重启后仍需先核对存档，日志不会自动恢复或补点。

成功提示和日志明确显示属性点、技能点的前后数量。保存校验同时确认原版保存回执的槽位和文件指纹，避免把后来变化的槽位视为本次结果。单纯的鼠标悬停提示不再阻挡退点及该流程中的原版存档；面板、对话框和地图等仍会阻挡。

材料规则继续使用 14 种宝石的基础价值合计至少 600、每次 1 次历练机会。地点、战斗、冷却、技能依赖与角色初始属性限制保留。

## 本地验证

- 原生、托管 Release 构建通过，无警告或错误。
- 完整 `scripts/test-offline.ps1` 回归通过，包含技能依赖、材料策略、原版存档接口、加点编辑、洗点、临时存档备份和恢复。
- 新增原生提交故障注入：点数写入丢失、刷新后点数未保留、撤回失败、部分材料扣除、最终核验失败、锁定后再次请求；并穷举已知界面标记组合。
- 托管退点检查覆盖连续退三次、点数守恒、重复退同一技能拒绝、扣了材料却没返还技能点的拒绝、持久化待核验记录、助手重新打开及损坏记录。
- 本次只读取本机操作日志、历史保险备份与当前存档作对比，未更改个人存档，未启动游戏实施退点。游戏内交互与异常注入仍需另行实测。
