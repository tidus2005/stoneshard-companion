## 修复与改进

- **修复一键备份的 PowerShell 模块依赖问题**：存档引擎改用随包 .NET，不再调用 PowerShell、ConvertTo-Json 或系统模块。无需安装 PowerShell，也无需修改系统设置。
- **备份目录可选择并记忆**：窗口显示真实存档/备份路径，Mac 虚拟机共享文档目录不可写时，可选择 Windows 本地目录；原目录的历史备份保留原处。
- 支持中文、空格、方括号、单引号、分号和长存档路径；保留旧 ZIP、SHA256 与管理器锁兼容性。
- 保留完整备份、最新副本、还原前保险备份及逐文件校验；加强异常 ZIP、并发写入与文件占用检查。
- 去掉随包 PowerShell 运行时，下载包更小。游戏功能及 v7 桥接协议保持不变。

升级时退出旧助手，将新版解压到一个新文件夹后运行，不要混合覆盖旧版文件。正常升级自 0.3.6 无需为了本次存档组件变更重启游戏；还原时仍应先让游戏停在菜单或退出。

本地及发行流程执行 353 项离线检查，并验证实际解压程序在没有 PowerShell 的子进程环境下备份、还原成功。测试只使用临时存档，未控制游戏、未修改个人存档；未在用户的 Mac / Windows ARM 虚拟机中实测。
