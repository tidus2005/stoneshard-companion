# v0.3.35 — 战斗预览、宝石混搭与退点核验

适配 Windows 10/11 x64、Steam Stoneshard 0.9.4.25 / Build 24780451。ZIP 为自包含免安装包，不需要另装 .NET 或 PowerShell。

## 新增与修复

- 新增实验性战斗悬停预览：三栏显示我的攻击属性、目标状态、对方普通近战下的防御预估。卡片穿透鼠标；Alt 展开，Ctrl+Alt+I 打开可滚动的完整数据快照，Esc 关闭。
- 退点支持原版全部 14 种宝石混搭，所选宝石基础价值合计至少 600 即可退回 1 点。每次仍消耗 1 次历练机会，超出价值不找零；可手选或自动凑够。
- 退点先修改并核验技能/属性及可用点数，再扣宝石和历练。结果不确定时锁定重复提交；日志持久化请求与备份信息，重启助手不能绕过同一游戏会话的待核验状态。成功后显示点数前后变化，并核验实际保存结果。
- 单纯鼠标悬停提示不再阻挡退点或相关原版存档操作。
- 助手兼容本项目确定指纹的解除 30 级封顶补丁，并放宽高等级角色的退点/洗点读取。**安装或更新助手不会自动修改游戏 EXE、等级或存档**；等级补丁脚本位于源码 `scripts/level-cap.py`，需单独备份并显式应用。

## 升级

先保存进度、正常退出游戏和旧助手，再将完整 ZIP 解压到新文件夹，运行 `Start.cmd`。桥接升级为 **v25**；只重启助手无法替换游戏进程中已加载的旧组件。在线更新同样需要等待游戏关闭。助手更新不迁移个人游戏存档。

## 验证范围与已知限制

本版完成原生/托管构建、离线回归及战斗卡片离屏界面检查。新增战斗测试为模拟引擎与离线模型测试，**不等于真实游戏验收**。

战斗预览仍属实验功能，尚未完成实际悬停目标、切换技能、各种 DPI 与原生查看面板逐项对照。技能特效、远程/法术、各部位护甲/伤势、状态剩余回合和最终伤害区间尚未精确适配；界面会提示缺失或未适配，不用普通攻击概率冒充技能预测。超过 30 级后的真实升级、奖励和存读档行为也尚未完成游戏内验收。
