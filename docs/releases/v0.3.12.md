# 0.3.12

- 方向键自动走图：沿人物当前行或列走到边缘后自动继续，到达实际出口格时向前进方向的相邻一格发送一次鼠标点击，触发原版切图。无需再按方向键，切图后不继续走下一张。
- 遇敌、受伤、打开面板、切到后台或手动操作会停止路线。没有真实出口、点击处被其他窗口遮挡或视口比例不匹配时停止，不重复点击。
- 包含 0.3.10 的 Parallels / Mac 共享目录备份修复，以及 0.3.11 的明确退出按钮、版本号、浮层层级和 GitHub 自动更新。
- 0.3.11 可通过设置中的“检查更新”升级；0.3.9 / 0.3.10 首次需要下载并完整解压。请保存进度并正常退出游戏，更新后重新启动以加载 v9 桥接。

验证：原生路线与点击坐标回归、托管离线回归、便携包校验和更新进程交接测试。自动走图尚需在实际游戏地图中验收；离线测试不代表实机切图已通过。
