# v0.3.13

- 自动切图改为到达边缘后，将系统鼠标移至人物前进方向的相邻格，分帧按下、松开左键。修正虚拟机缩放与画面留黑坐标；失焦、遮挡、手动移动鼠标或出现危险时取消。
- 新增左侧半透明角色属性面板：分类、全部／特别关注、悬停星标、保存关注列表，悬停查看游戏提供的基础值与来源。未能取得的基线与来源明确显示不可用；尚不支持完整还原所有力量、技能、伤势及敌方效果的逐项计算公式。
- 新增马车饲料按钮和材料配置：只消耗背包中勾选种类的原版可用材料，通过原版配方制作。默认不选材料；右键饲料按钮打开配置。选择按材料种类保存，一次制作会消耗所选种类的全部合格材料；不会自动拾取地面物品。

本版完成编译、模拟鼠标／地图／配方测试和离线回归，尚未做游戏内实测。按用户要求，开发验证没有操作正在运行的游戏。

桥接协议升级到 v10。请在结束本次游玩后正常退出游戏和旧助手，再运行新版并启动游戏；不能在已加载旧桥接的游戏进程中热替换。本版不会替你强制关闭游戏。
