# v0.3.36 本地候选版

2026-10-15。当前公开下载仍为 v0.3.35；本文件不表示新版已公开发布。

- 桥接 v26：窗口回调检测 YYC 活跃脚本帧；游戏原生脚本执行中延后桥接命令及采样，在后续空闲 tick 按原命令序号、期限和场景条件执行一次。退出回调时恢复 self、实例查询上下文和脚本帧。
- 移除重复战斗采样和 refresh_scene 中遗漏的临时对象释放。
- 区分 VM/modbranch 数据包和指纹不匹配的 YYC 数据包，提供明确原因与 EXE/data.win SHA256。未知版本保持停止连接，存档管理仍可独立使用；未实现通用模组兼容。
- `Ctrl+Alt+F5` 保存当前进度，托盘和设置页可找到同一入口；`Ctrl+Alt+B` 仍只备份已落盘存档。
- 出发清单：可编辑通用检查事项，勾选只属于本次窗口；无自动物品操作、无额外游戏信息。
- 仓库启动脚本按项目版本选择本地构建，避免一直启动旧的 0.3.35 开发目录。

本地运行：仓库的“启动晶石助手.cmd”会选择 `artifacts/development/0.3.36/app`。升级前正常保存并退出游戏、退出旧助手，再重新启动游戏；v25 游戏进程不能热换成 v26。

验收：构建和全套离线回归通过，新增 18 项数据包检测、8 项脚本上下文检查通过，清单界面离屏检查通过。使用独立 ShardTest0 角色副本持续采样 360.2 秒，完成 687 次刷新，原生采样累计推进到 4049，期间未见同类致命报错；随后角色从 (1105,1131) 原生走图到地图中心 (1183,1183)，状态为已到达，并成功写入、验证 `character_3/autosave_1` 的数据、元信息与截图。个人原存档 65 个文件在测试前后哈希一致。

验收边界：这是营地内持续运行及一次短途走图/保存测试，不代表所有地形、长途探索或反馈者环境都已覆盖。Steam Rich Presence 评论报错的具体根因尚未在反馈者环境复现，不能视为已彻底解决。模组版只改善诊断，没有放宽地址/指纹校验或安装第三方模组。10 月 16 日补测已验证真实快捷键注册、原版保存及 Load 读回；但完整流程在后置备份阶段发生测试进程提前退出，纯备份夹具也能复现，尚未定位原因。该问题排除前不正式发布。详见 [补测记录](../验证记录-2026-10-16.md)。
