# 逐点退回（0.3.30）

在助手设置中点击「逐点退回」，进入地图后读取当前角色。属性和已学技能旁的减号会弹出确认框；确认后只退回这一点，回到游戏原有的属性点或能力点池。重新分配使用原版 C / S 界面。

- 属性点：每点 250 克朗；技能点：每点 500 克朗。费用是助手的自定义平衡规则，非官方价格。小幅调整比整套重练便宜，反复换流派则按点累积成本。
- 可以在游戏运行时操作。需停步、关闭原版菜单、脱离战斗，并等待技能冷却结束。
- 不降低等级或经验，不增加点数总量，不退回角色初始属性或免费基础动作。
- 技能依赖直接读取当前原版技能树的连接结构，遵循其 AND / OR 分支。仍有已学技能依赖时，按钮提示要先退回的后续技能；原生端也会再次检查。
- 德温的生存树涉及种族特性赠送属性点，目前暂不开放退回，避免重复领取。
- 每次先调用原版保存并备份当前进度，确认角色和金币未变化后再扣款、退点、刷新技能缓存与属性。成功后再次保存并核对落盘结果。
- 金币不足、状态变化、依赖不满足会拒绝操作。提交后发生异常会给出保险备份路径并要求不要重复点击。
- 旧版组件已经载入游戏时，升级后需要正常重启游戏一次；之后每次退点无需退出。

该功能依赖当前受支持的游戏版本 0.9.4.25。技能名称和图标读取本机游戏资源，发行包不附带原版游戏素材。
