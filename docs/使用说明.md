# 晶石助手 0.3.16（本地迭代版）

适用于 Windows 10/11 x64、Steam 原版 Stoneshard **0.9.4.25 / Build 24780451**。

## 启动与升级

本地迭代直接双击项目根目录的 **启动晶石助手.cmd**，运行当前 Release 构建。代码更新后先退出助手，执行 `scripts/build.ps1`，再重新启动；如果桥接组件也有更新，需要正常退出游戏后再构建。本版已在 Mac 的 Windows ARM64 虚拟机内实测。

使用已发布的安装包时，从 [GitHub Releases](https://github.com/tidus2005/stoneshard-companion/releases/latest) 下载对应版本的 `win-x64.zip`，不要下载自动生成的 Source code：

1. 完整解压，保留 EXE、StoneshardBridge.dll 和 Assets 文件夹。
2. 退出旧助手，将新版完整解压到新文件夹，不混合覆盖。**本版更新了游戏桥接组件；请保存进度并正常退出游戏，退出旧助手后再启动新版和游戏。只重启助手会继续遇到旧桥接组件提示。**
3. 双击包内 `Start.cmd` 或 `StoneshardCompanion.exe`。无需另装 .NET；存档管理直接使用助手自带的 .NET，无需 PowerShell、模块或执行策略设置。源码工作区也可使用根目录“启动晶石助手.cmd”。
4. 助手启动即显示面板；游戏使用窗口或无边框全屏。保存退出、主菜单、加载、断线或游戏关闭后，仍可直接点击面板备份和管理存档。

本版优化沿途自动采集：无需刷新或勾选材料，按原版支持的浆果、药草采集，制作合堆后恢复原路线。实际验证范围见 [0.3.16 验证记录](releases/v0.3.16.md)。

## 单面板与物品常显

拖动面板顶部移动位置；鼠标移到四角出现缩放指针，拖动改变宽高。九宫格导航固定在面板最左侧；宽面板和高面板自动重新排列右侧功能按钮，空间较小时收起文字，悬停图标可查看说明。位置、尺寸自动保存。设置中的“恢复默认面板位置与大小”可重置布局。

上方显示饥饿、口渴、疼痛、迷醉；未知或过期数值显示“—”。面板只在打开状态栏、物品栏或装备栏时临时隐藏，关闭后恢复；其他菜单、后台、断线和游戏退出不自动隐藏。未连接或不在游戏前台时，移动、面甲、补给等游戏操作禁用，备份和设置仍可使用。手动“收起”继续有效。物品常显直接作用于地面名称的显示判断，移动、点击和装备界面切换时继续显示，无需按住 Alt。对话、确认框、世界地图、加载、后台或助手失联时暂停增强显示，恢复后继续使用原选择。仅显示原版允许看到的物品，不揭开迷雾；关闭增强后仍可正常按 Alt 显示。

## 九宫格导航与自动跨图

左侧按钮固定排列：

```text
 ↖  ↑  ↗
 ←  ◎  →
 ↙  ↓  ↘
```

点击上、下、左、右，角色沿原版寻路到达对应边缘，再将系统鼠标移到人物前进方向的外侧出口并点击。向上会额外提高点击位置以避开头部。每次只跨一张相邻地图，加载后结束。九宫格的四个斜向按钮到达角点后停下。两个“地图中心”按钮都让角色行走；中心不可达或有单位占用时，从北侧开始沿顺时针方环向外扫描，选择第一个空闲且原版寻路可达的格子。Ctrl + Alt + C 仍只调整镜头。

行走中点击任一九宫格按钮，或按 **Ctrl + Alt + End** 停止。方向快捷键为 **Ctrl + Alt + 方向键**；角色走到中心为 **Ctrl + Alt + Home**。手动点击、操作按键、开包、切到后台、出现敌人、受伤或地图变化都会取消当前路线，不攻击敌人，不自动续走。抵达边缘后的出口步骤也执行相同检查，出口点击前检查遮挡与危险，不强制切换房间。

保留原版回合与移动消耗。目标或出口不可达、路线中断、长时间无进展时停止，不反复寻路或点击。路线受地形、障碍、已探索区域和原版规则限制；所选边缘无可用出口时需要自行选择其他位置。自动补给在整个行走及跨图过程中等待。

## 方向键自动移动

点击顶部“方向键自动移动：关”开启，或在设置中勾选同名选项。开关默认关闭，选择会保存，切图和重连后恢复。状态“待命”表示已选择开启，正在等待有效游戏连接或前台可操作地图。

轻按普通 **↑ / ↓ / ← / →**：上、下保持人物当前列，左、右保持人物当前行，使用原版寻路到对应地图边缘后，自动沿人物当前行或列点击外侧相邻格触发出口，跨入相邻地图后结束，不继续走下一张。已通过手动操作走到出口附近时，同样可以直接按对应方向切图。目标按当前人物和地图坐标计算，与镜头位置无关；地形可能使原版路径绕路，不保证全程直线。

同时按两个垂直方向键：↑＋← 西北、↑＋→ 东北、↓＋← 西南、↓＋→ 东南。以相同的横纵格数走向先到达的边缘，再自动跨一张地图；原版寻路可能绕开障碍。两个键需同时按下（150 毫秒内），长按不会反复触发。

途中再轻按任一普通方向键停步；到达对应边缘后自动点击出口。需要松开再按才发起新路线；长按不会重复发起或恢复已中断的路线。关闭开关会停止键盘模式发起的行走，九宫格独立路线保持不变。“停止并恢复正常”同时关闭此模式和所有助手行走。

普通方向键只在游戏窗口中处理，不注册全局普通方向键；后台、加载、状态栏、背包和对话中保留原操作。Ctrl / Alt / Shift / Win 组合不触发此模式，原有 Ctrl + Alt + 方向键跨图快捷键保留。遇敌、受伤、手动操作、面板、切图和超时后停止，不自动攻击或续走。

## 喝水与火把

点击水袋喝一次，按钮说明显示随身饮水剩余次数。右键水袋可开启自动喝水，也可在设置中调整口渴阈值，默认 25%，范围 10%～80%。优先使用剩余次数少的可用容器，跳过箱子和不可用饮水。自动喝水确认口渴下降及数量减少后，仍高于阈值才继续，动作间隔至少约 3 秒。

点击火把切换点亮/熄灭；需要时通过游戏原生装备操作使用随身火把。右键火把开启“自动保持点亮”：火把耗尽后尝试使用备用火把，保留原版手部装备限制。此选项不判断昼夜，会持续保持照明。手动点击火把会关闭自动保持，避免刚熄灭又被自动点亮。

自动补给仅在游戏前台、地图就绪、无敌人且角色空闲时执行；移动、受伤、菜单、加载、拖动面板和备份期间等待。保持原版物品、持续时间和回合消耗。未收到确认时暂停自动补给，重新开启选项才重试。两种自动化默认关闭。

## 存档管理

面板右侧“备份”图标直接创建完整备份；文件夹图标打开管理窗口。也可从设置或系统托盘打开。

- **一键完整备份**：备份全部角色与设置，建立时间命名的历史 ZIP 和校验文件。
- **本地备用备份**：先在 Windows 本地生成并校验完整 ZIP，再复制到所选目录。传输失败时保存该 ZIP 和 `.sha256`，点击此按钮可打开保留目录；目标恢复可写后，复制这两个文件到备份目录再刷新列表。成功传输的临时文件自动清理。目标目录一开始不可访问时会直接报错，尚不会生成本地副本。
- **刷新最新备份**：新增历史备份，同时更新 `Stoneshard-latest.zip`，保留旧历史。
- **历史列表**：在后台读取，进度更新不重复扫描共享盘；普通备份按时间排列，保险备份放在后面。可刷新列表、打开备份目录。
- **还原选中备份**：先展示所选文件和说明，再确认还原。还原前自动建立当前状态的保险备份，校验源 ZIP，文件恢复后比对哈希。损坏、路径异常、占用和并发写入会中止并报告。

0.3.9 允许所选存档或备份根目录经过 Windows 目录链接、重定向“文档”目录；解析实际位置后重新检查存档与备份不能互相包含。云文件和虚拟存储的非路径替换标记不再一律拒绝。存档内部的符号链接仍拒绝，防止越界或循环。报错包含版本、步骤和错误码，可点击“复制状态与路径”反馈。

默认存档目录 `%LOCALAPPDATA%\StoneShard`，备份目录“文档\Stoneshard Save Backups”，兼容原命令行管理器的已有备份。窗口显示可复制的实际路径；点击“选择备份目录”可改为 Windows 本地磁盘或其他可写目录，选择会保存，原目录中的历史备份不会移动或删除，切回原目录即可继续查看。Mac 虚拟机的“文档”可能重定向到共享目录；若共享目录断开或不可写，请选择 Windows 本地备份目录。两个管理器使用同一操作锁；原命令行管理器仍开着时，应先退出它再执行图形存档操作。

备份只包含**游戏已经保存到磁盘的进度**。本工具不会强制让游戏落盘。还原不会替你关闭游戏；应先停在主菜单/死亡界面，或正常退出游戏，再确认。旧版运行中热还原曾出现加载失败，因此“文件哈希还原成功”不代表“游戏已成功读档”，目前尚未完成该项实机验证。操作过程中等待完成再退出助手。

程序兼容性与游戏桥接兼容性分别判断：当前发行仍是 Windows x64 程序，不是 macOS 原生程序；Windows ARM 虚拟机依赖系统的 x64 兼容运行能力，本版已在一台 Mac 的 Windows ARM64 虚拟机实测，其他 VM、DPI 和硬件配置仍需分别验收。路径支持中文、空格和方括号等字符，文件操作不经过命令行解释。共享目录仍需可读写并支持可靠的文件锁。

## 速度及适配边界

点击速度图标立即按 **正常 1× → 加速 2× → 急速 3× → 正常 1×** 循环，三个不同的箭头图标与倍率文字显示当前选择，不再打开下拉菜单。原有 Ctrl + Alt + 1 / 2 / 3 / 4 快捷键保留；若通过旧快捷键选择了 4×，再次点击速度图标回到正常 1×。

同一游戏进程内，切图、菜单、后台及重连不会清除所选倍率。状态栏、物品栏和悬停说明保持当前倍率；暂停菜单、对话、确认框及世界地图暂时恢复正常速度，恢复游玩后继续原倍率。主动选择 1× 或停止后不再恢复旧倍率。新游戏默认 1×，设置可开启“下次启动游戏沿用倍率”。

加速整个引擎步进，包括移动和动画；不增加每回合移动距离。面甲保留原版限制；镜头居中只移动视角，不缩小画面或揭开迷雾。完整游戏文件指纹不符时拒绝连接，不兼容修改 data.win 的 Mod。

本机设置与日志：`%LOCALAPPDATA%\StoneshardCompanion\`。助手不修改游戏安装文件；存档功能读写存档/备份，正常游玩仍由游戏自行保存进度。正常退出助手结束走图并恢复速度；异常失联后游戏组件在心跳超时并恢复处理消息时停止路线、恢复速度和原版物品显示。

图标授权见 `Assets\Icons\ATTRIBUTION.md`；备份、历史和三档速度图标由本项目绘制。


## 属性面板与外观

从行旅辅助顶部“设置”打开总控，无需退回桌面。两个浮窗的背景不透明度和边框可独立配置；属性面板宽度、高度、字号即时生效并保存。0% 仅使背景透明，文字保持可读。默认属性面板为 290 × 380，标题可拖动。

属性支持分类、“全部”和“★ 特别关注”。鼠标移到属性行右侧点击星标，关注列表自动保存。悬停查看当前值、已知基线、基础属性贡献与游戏记录的效果来源。力量 22 时，兵器伤害中的力量贡献为 (22 − 10) × 1.5 = 18 个百分点。未读取到的基线显示 —；其余净变化不冒充某个具体技能或伤势，来源列表也不能直接重复相加。

## 马车饲料

右键饲料按钮打开配置，顶部是沿途自动采集开关。下方背包材料勾选只用于手动一键制作，记住种类；手动制作一次消耗所选种类的全部合格材料。自动与手动制作都通过原版配方，将成品优先合入已有饲料，达到原版上限后剩余部分才占用新格。背包放不下时保留在制作面板，不丢弃、不重复制作。

## 补给续航与耐久

行旅辅助下方显示食物、水预计可支撑的游戏小时或天数。以饥饿、口渴达到 25% 时补充为界限，累计至少 6 分钟游戏内行动时间后，从实际需求增长估算消耗率；暂停现实时间不会减少续航。设置中可手动指定每游戏小时增长量，填 0 使用实测。

估算包括当前饱腹／水分、随身食物和饮水次数、已读取的回复量及剩余保鲜时间。一次回复超过 25 点的部分保守按 25 点计算；未读取到回复量的食物显示 — 并排除，未把食物汁水和药酒当饮用水。悬停查看明细。天气、盐分、后续状态与战斗会改变实际消耗，数字用于近似规划。

装备达到耐久预警线显示黄色，耐久为零显示红色；悬停查看每件装备名称、当前／最大耐久及百分比。默认预警 25%，可在设置里调整。

## 存档截图与自动更新

选中历史备份，右侧读取该 ZIP 内最近的游戏原生截图，优先最近使用的角色，标注时间和槽位。截图属于游戏上次落盘的存档，可能早于备份操作；没有截图的旧备份仍可正常还原。

设置里的自动更新从 GitHub 最新正式发行版检查版本，下载完整包并验证校验值。游戏运行时等待，关闭游戏且存档操作结束后安装并重启助手；失败保留当前版本。也可点击“检查更新”。桥接升级必须重新启动游戏。

## 自动采集与面罩（0.3.15）

右键行旅辅助的“饲料”，打开“选择饲料材料”。窗口从当前主背包读取原版允许制作饲料的材料；捡到新材料后点击刷新，勾选要长期使用的种类。名称和选择会保存，用完后仍显示并保留勾选，不需要重新拾取再配置。

开启“行走途中自动采集并制作饲料”后，无需扫描按钮、刷新或勾选：自动路线途中发现视野内原版可做饲料的浆果、药草，就走到可达的相邻格，用真实鼠标点击采集，将背包中的这类材料制作、合堆，再恢复原目标。取消旧的 8 格限制，以原版可见性为准，不会探索迷雾。默认 17 种浆果和普通药草；大黄、小扁豆（含棵子）、韭葱、蔬菜等食材保留，不自动消耗。橡子在当前原版没有饲料值，不参与转换。发现逻辑在人物移动期间持续运行，暂时不可达的目标会冷却后重试，不再整张地图永久跳过。遇敌、手动操作、切到后台或开包都会停止；背包放不下结果时保留原版制作面板供整理。达到原来的终点或跨入相邻地图后结束本次行走。

手动面罩旁边的“自动面罩”可以独立开关。原版敌情或受击状态出现时关闭，安全持续 1.5 秒后打开；操作遵循原版回合限制。手动开合面罩会关闭自动模式。“停止并恢复正常”同时关闭这两项自动功能。

还原备份时，“已回到游戏主菜单”确认框默认勾选，仍需点击最后的还原按钮。请在主菜单或退出游戏后还原。
