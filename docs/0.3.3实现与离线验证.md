# 0.3.3 实现与离线验证

本次按用户要求只修改代码、运行离线检查和构建成品，没有启动游戏、助手窗口或实机调试，也没有操作正式存档。0.3.2 的实机结果属于历史版本，不能当成本版自动跨图和布局的实机验收。

## 最终行为

- 左侧固定一个 3×3 十字导航：上、下、左、右和中央 ◎。中央按钮让角色行走到地图中央，右侧原有镜头居中保留。右侧 12 个功能按钮独立自适应排列，拖动和四角缩放仍可使用；为容纳十字键，最小尺寸调整为 356×200，默认 650×216。
- 四向走图先沿原版路径到对应边缘中点内侧，再检查敌人、受伤、角色空闲、菜单、场景、前台和修饰键状态，通过后只向最外层出口格发起一次原版移动。正常切图由游戏处理；一旦进入加载或场景改变，本次路线结束，不连续跨下一张地图。
- 中途出现敌人或受伤时取消路线，不调用攻击脚本。手动操作、后台、打开菜单、失联、人物变化及无进展也会停止；中断后不补发出口点击。没有出口或出口不可达时报告停止，不强制切换房间或反复点击。
- 方向快捷键仍为 Ctrl+Alt+方向键；新增 Ctrl+Alt+Home 走到中心，Ctrl+Alt+End 停止。行走中点击任一十字键均为停止。
- 面板显示与可操作状态分开。只有当前可靠状态表明状态栏/物品栏打开时临时隐藏；主菜单、保存退出、后台、加载、断线及游戏关闭后仍显示。游戏按钮在不可操作时禁用；备份、存档管理和设置保留。手动收起、退出助手仍生效。
- 备份状态优先于已完成的路线状态，退出游戏后不会被旧行走提示遮住。备份仍只保存已落盘进度，不代替游戏保存。

## 原版跨图调用依据

本地已安装版本为目标 YYC 构建。静态反汇编显示 `o_player.Other_17` 调用 `scr_playerTileborderTransition`，该函数按人物与边界对象的网格坐标判断原版转换流程。助手继续使用已有 `scr_player_move` 发起原版路径，不直接调用房间跳转或写入人物坐标。

2340×2340 地图的内侧目标为 `(1183,39)`、`(1183,2301)`、`(39,1183)`、`(2301,1183)`；出口步骤为对应外侧格中心 13 或 2327。中心目标为 `(1183,1183)`。其他地图按原版 26 像素格计算，异常尺寸拒绝执行。这是静态实现依据，真实地图的出口通路与转换结果尚未实测。

## 验证结果

`scripts/test-offline.ps1` 全部通过，构建无警告、无错误：

- 27 项原生补给检查。
- 62 项原生显示/行走检查：四向先到内侧再发一次出口请求、中心不跨图、起点已在边缘/中心、出口前遇敌/受伤/菜单/后台/手动接管、出口步骤遇敌停止、出口无响应不重试，以及新地图不接续。
- 39 项速度意图检查。
- 61 项托管检查：500 组拖动输入、窄/宽/高布局、退出/菜单/断线后的可见性、按钮操作限制、协议解码及临时存档回归。
- 8 项独立存档核心回归，仅使用临时目录。

桥接协议升级到 v5，加入跨图阶段字段，读取大小为 3968 字节；原生布局断言和托管测试验证尾部字段及旧长度拒绝。检测到游戏中仍加载 v1～v4 时要求正常重启游戏，避免新界面连接旧逻辑。

日志在忽略目录 `artifacts/offline-v033-final.log`。成品使用独立的 `artifacts/release/StoneshardCompanion-0.3.3/` 目录及同级 ZIP，旧成品保留；根目录启动器指向 0.3.3。发布文件和 ZIP 的哈希校验结果记录在 `artifacts/release-verification-v033.json`。

新十字布局的真实画面、自动跨图、复杂敌人事件及保存退出后的真实界面保留尚未做实机验证。旧版关于组合键模拟输入、DPI、火把和热还原的未验证边界继续适用。
