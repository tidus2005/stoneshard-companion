# 家庭电脑开发交接

当前版本：v0.3.17。开发分支：`fix/windows-vm-backup`，不是 main。

## 获取与启动

首次获取：

```powershell
git clone --branch fix/windows-vm-backup https://github.com/tidus2005/stoneshard-companion.git
cd stoneshard-companion
```

已有仓库时先保存自己的修改，再执行：

```powershell
git fetch origin
git switch fix/windows-vm-backup
git pull --ff-only
```

开发依赖：Windows、PowerShell 7、.NET 8 SDK、Zig 0.13.0。将 dotnet 和 zig 加入 PATH，或将 Zig 放入 `.tools/zig-windows-x86_64-0.13.0/zig.exe`。CI 的精确安装与发布流程见 `.github/workflows/release.yml`。

```powershell
pwsh -NoProfile -File scripts/build.ps1
```

编译后双击根目录 `启动晶石助手.cmd`，运行本次编译的 Release DLL；每次修改后重新编译并重启助手。桥接改动需要正常退出并重启游戏。可直接使用 GitHub Release 的免安装包，无需开发依赖。

离线回归与发行包：

```powershell
pwsh -NoProfile -File scripts/test-offline.ps1
pwsh -NoProfile -File scripts/build.ps1 -Publish
```
