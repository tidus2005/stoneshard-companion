# 鼠标悬停战斗预览：设计与本地首版

2026-09-27，助手 0.3.35 / 原生桥接 v25。适配 Stoneshard 0.9.4.25，以及本项目已验证指纹的解除 30 级封顶补丁。

## 交互

鼠标悬停当前可见、存活的单位时显示三栏卡片。卡片优先位于鼠标上方，靠近顶部时移至下方，并限制在当前显示器工作区内。卡片完全穿透鼠标，不获取焦点，也不执行攻击。普通攻击和技能仍使用游戏原有快捷键。

按住 Alt 显示更多抗性和状态来源。Ctrl+Alt+I 打开可滚动的完整数据快照，展示双方当前可读取的全部属性、目标状态及己方修正来源；快照记录时间，明确不随目标变化更新，Esc 关闭。在设置中可关闭悬停预览。

移动到其他目标、单位死亡、进入迷雾、打开菜单、切换地图、切到后台或数据过期时清空卡片。鼠标已经离开采样位置时也隐藏卡片，避免把上一个目标的信息挂到新目标上。

## 三栏内容

| 区域 | 内容 | 数据口径 |
| --- | --- | --- |
| 我 → 目标 | 当前技能选择、准确、失手、暴击、主副手伤害、护甲穿透与护甲损伤；普通近战概率；状态来源 | 当前属性已包含生效状态，来源只解释，不重复相加 |
| 目标当前状态 | 生命/上限、能量/上限、防护、耐久、闪避、格挡、格挡能量、反击、各类抗性、活动状态 | 从目标实例读取；缺失字段显示 —，列表不完整会注明 |
| 目标 → 我 | 对方攻击属性、己方闪避/格挡/抗性，以及假设普通近战的受击概率 | 当前快照下的条件预估，不预测敌方 AI、技能选择或我方出招后的状态 |

目标技能清单不属于此功能。完整数据窗口列出所有已经读取的字段，不意味着原生查看界面的所有部位信息已经适配。

## 计算规则与限制

准确、闪避、失手分别判定，不能把“准确 − 闪避”直接作为最终命中率。官方说明：[City of Gold 战斗规则调整](https://store.steampowered.com/news/posts/?appids=625960&enddate=1637711065&feed=steam_community_announcements)。

首版普通近战模型：

- `a = clamp(准确 − min(闪避, 0), 0, 100) / 100`
- `d = clamp(闪避 − max(准确 − 100, 0), 0, 100) / 100`
- `f = clamp(失手, 0, 100) / 100`
- 正常或暴击命中（格挡前）：`a × (1 − f) × (1 − d)`
- 擦伤：`a × [f × (1 − d) + (1 − f) × d]`
- 完全落空：`1 − 正常命中 − 擦伤`

这些数字明确标为估算，不保证造成生命伤害。格挡可能只挡掉部分伤害，护甲和抗性在后续结算。面板主副手伤害不包装成最终伤害区间；护甲损伤不直接从本次防护数值扣除。

**尚未实现精确适配的部分：**各技能参数与条件触发、双持连击、远程距离与遮挡、法术、受击部位与各部位护甲/伤势、状态剩余回合。选中技能时停止输出普攻概率，保留角色面板数据并注明技能特效未适配；远程/法术类型不套普通近战公式。当前敌方普通近战预估也不代表它下一回合一定能攻击。

## 数据与安全边界

- 原生数据在现有游戏事件线程中读取，每 120 ms 至多采样一次。调用原生鼠标位置与碰撞查询获取悬停单位，并要求单位存活、可见、鼠标格不在迷雾；不扫描整张地图。
- 读取单位属性和活动状态列表；己方属性来源复用已适配的 `buffer_buff_list`。没有调用攻击、伤害、技能施放或随机数脚本，不改变游戏值和存档。
- 独立 8192 字节快照，与原有状态共用 seqlock；新增区域从 120704 开始，仍在原有 131072 字节映射内。桥接版本递增为 v25，拒绝同进程旧版组件。
- 快照带单调时间、场景代数、目标 ID 和鼠标屏幕坐标；450 ms 过期，鼠标移动超过采样容差时隐藏。缓冲溢出清空结果，缺失字段不补零。
- 保留已有退点修复与等级补丁指纹校验。旧助手注入过的游戏需要正常退出并重新启动后才能使用 v25。
