# 0.3.2 修复与实机验证

日期：2026-09-06。适配 Steam Stoneshard 0.9.4.25 / Build 24780451。Windows 本机运行真实游戏，使用独立的 `ShardTest0` 存档空间及测试安装目录；正式 `StoneShard` 存档未参与游玩或还原。

## 本次改变

- 状态栏、物品栏、悬停说明不再暂停加速，打开面板期间仍可选择倍率。暂停菜单、对话、确认框和世界地图继续暂时恢复原速；切图及重连保留所选倍率。
- 物品常显仅增强原版地面名称的创建和保留判断，移动、装备栏切换时继续显示。没有模拟按住 Alt，也不改变移动和攻击的输入判断。版本校验除完整文件指纹外，还检查目标函数与两个调用位置；校验失败不会安装显示增强。
- 新增脚印方向菜单、`Ctrl+Alt+方向键` 四向走图、`Ctrl+Alt+End` 停止。调用原版寻路，每次一条路线，走到边缘中点的内侧格；不瞬移、不自动穿过下一张地图、不在中断后重试。
- 走图遇到菜单、后台、敌人、受伤、场景变化或无进展时结束。手动输入在交给原版处理前先停止旧路径，避免旧路径残留，也避免后续计时器取消玩家新选的路径。补给自动化在走图期间等待。
- 桥接协议升级为 v4。已有 v1～v3 桥接时提示正常重启游戏；不尝试在运行中的旧桥接上覆盖升级。

## 离线与发布检查

`scripts/test-offline.ps1` 成功完成：27 项原生补给检查、39 项原生显示/走图检查、39 项倍率意图检查、43 项托管检查（包含 500 组布局输入及 13 个 HUD 操作），以及 8 项存档核心回归。原生检查使用模拟 GameMaker 调用；存档回归仅使用临时目录，不能代替游戏实测。

Release 构建及自包含发布成功，构建日志无警告、无错误。最终菜单交接修改后，重新通过 39 项倍率意图和 43 项托管检查，并启动发布成品完成 round6。成品为 `artifacts/release/StoneshardCompanion-0.3.2/` 及同级 ZIP；根目录启动器指向 0.3.2。已核对 `SHA256.json` 的 6 个文件，以及 ZIP 中含清单在内的全部 7 个文件，内容一致；结果在 `release-verification.json`。

最终测试正常保存返回主菜单并关闭测试游戏，随后退出助手。正式存档测试前后均为 54 个文件，逐文件路径、长度和 SHA256 比对差异为 0，结果在 `formal-integrity.json`。助手偏好已恢复到测试前备份，文件哈希一致；退出与恢复结果在 `cleanup.json`。测试角色的游玩变化只在隔离存档中。

## 验证边界

- 测试工具合成很短的 Ctrl+Alt 组合键时，出现过原版攻击光标残留；再按一次 Ctrl 可恢复。本次没有改写游戏攻击模式或强制清空玩家输入。尚未用物理键盘确认是否也会出现此现象，不能宣称所有输入方式均已验证。
- HUD 的坐标自动点击出现过偏移、点到相邻开关的样本，不计为菜单执行成功。最终改用可访问控件定位，上下方向均有确认日志和实际位移；菜单关闭后再派发及前台交接等待也已随最终版验证。自动化坐标偏移不能据此推定为普通鼠标操作故障。
- 普通可达地图的四向寻路已验证；密集战斗、受伤瞬间、地牢复杂障碍、未探索地图、手柄输入、多显示器、不同 DPI 和长时间耐久尚未完成实机覆盖。敌人、受伤、无进展、失联等停止条件有离线检查，未实测的场景不列为实机通过。
- 四向走图遵守原版可达性。目标被挡住时结束，不保证每张地图的边缘中点都有通路；不包含自动连续跨图。
- 本轮未重新验证自动火把、真实饮水和运行中存档还原；历史报告的限制继续适用。
