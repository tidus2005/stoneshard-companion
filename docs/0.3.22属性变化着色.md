# 0.3.22 属性变化着色

- 属性行保留当前值的中性色，将括号内相对基线的净变化着色：改善为绿、变差为红，无变化或未知为灰。
- 按属性含义判断方向：失手、反噬、承伤、能耗、冷却修正、噪音及负面状态越低越好；不按加减号直接决定好坏。疲劳增长字段的具体数值约定尚未确认，暂保留中性色并说明。
- 悬停显示分层卡片：当前结果、对比基线、基础属性影响、游戏记录的来源；变化配加减号、箭头、颜色和文字。来源为原始修正，不冒充相对于手动基线的新增效果，也不与基础属性贡献重复相加。
- 说明过长时可滚动，使用面板主题；过期数据不展示旧的增益结论。

验证：离屏截图与真实视图颜色断言、效果方向及中性边界回归、托管离线检查。未启动新版助手或操作游戏。原生桥接版本保持 18，此次为助手界面更新。
