# 0.3.20

- 桌面“晶石助手（开发版）”快捷方式指向项目启动脚本，脚本启动 0.3.20 开发构建。
- 采集默认保留量全部为 0；首次读取旧配置会保留副本并统一归零一次，后续自定义数量不再重置。数量旁提供深色 ▲/▼ 按钮，可长按连续增减。
- 增加“鸟蛋（从鸟巢采集）”。勾选后将数量设为正数才能补齐；保留 0 表示不保留鸟蛋。沿用原版鸟巢采集、可见性、距离和背包容量检查。
- 耐久预警支持 0–100%，包括 80%；含义仍是耐久低于所设百分比时预警。
- 从正在运行的游戏、STONESHARD_DIR、Steam 安装信息和库目录探测游戏位置。配置统一到游戏目录下的 StoneshardCompanion/preferences.json，设置页显示实际目录。未找到游戏时暂用原本地目录。
- 从旧本地配置复制迁移，不覆盖已存在的共享配置，旧文件保留。支持此机制的新版本共用同一路径；已经编译的旧版程序仍按其旧逻辑读取配置，需更新后使用共享路径。

验证：完整离线测试通过；鸟蛋采集阈值、归零迁移、迁移不覆盖、后续自定义量保留、增减按钮、耐久 0/80/100 重载及离屏预览检查通过。静态确认 o_interactive_nest 继承 o_interactive_harvest，berryType 指向 o_inv_wildegg。未进行游戏内操作。桥接版本 17，需要退出游戏和旧助手后重新启动进行实测。
