# 0.3.24 快速备份与读档

行旅辅助新增“快速备份”“快速读档”。快速备份保存已落盘的游戏存档，成功后将该手动备份路径写入游戏目录的共享配置。存档管理内的“保留一份手动备份”也会更新这个目标。

更新当前状态、latest、还原前保险以及还原操作都不改变快速读档目标。首次使用会识别当前备份目录中最新的明确标注为手动备份的文件；旧版来源不明的文件不自动采用。目标删除或切换目录后找不到时，提示用户重新备份或切回目录，不自动替换为别的存档。

快速读档直接打开置顶的存档窗口，选中目标并在顶部展示备份时间和还原确认。核对目标并确认游戏处于主菜单、死亡界面或已退出后执行既有还原流程；完成后需要在游戏内重新读档。快速备份不会触发游戏内保存。

验证：隔离构建零警告零错误；真实 WPF 控件加临时存档回归通过，包含手动目标持久化、连续三次 latest 不改变目标、下一次手动备份推进目标、迁移不采用自动快照、目标丢失不回退、快速读档确认前不写存档。离屏布局检查通过，确认按钮仍在列表上方。未重启助手、连接游戏或操作真实存档。

桌面开发版快捷方式及两种启动脚本均指向 artifacts/development/0.3.24/app，继续使用 dotnet 主机。
