# 0.3.21 背包处理

开启行旅栏的自动采集后，打开游戏背包并停止按键／鼠标操作约 1.2 秒，会处理背包内的物品：

- 丢弃七种浆果对应的原版腐烂变体（越橘、树莓、蓝莓、红莓、醋栗、小檗果、葡萄）。只匹配确切物品标识，不按名称含“腐烂”泛匹配，不处理其他食物、商人物品、箱内物品或地上物品。
- 对已勾选自动剥取的小扁豆植株，触发原版物品右键菜单中的 Flay 操作。背包关闭时不再触发剥取，也不直接调用地面操作或删除源物品。
- 每次只发出一次操作，确认物品离开背包，或植株消耗并且背包豆籽数量增加后，才继续下一件。原版拒绝或结果未确认时暂停；关闭再打开背包可重试。
- 腐烂浆果计入采集完成确认，但不计入正常浆果保留量，避免反复点击已经采过的目标。

本次只构建和离线测试，未重启助手、未注入当前游戏、未操作真实存档。模拟用例覆盖背包关闭、物品所有权、拖动保护、后台保护、丢弃拒绝及结果确认；原生右键事件在实际游戏中的表现仍需用户重启测试。桥接版本为 18。
