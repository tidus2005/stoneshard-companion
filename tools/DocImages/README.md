# 文档界面预览

在仓库根目录使用 Windows 和 .NET 8 SDK 运行：

```powershell
dotnet run --project tools/DocImages/DocImages.csproj -c Release -- .
```

输出四张 2 倍分辨率 PNG 到 `docs/images/`：宽面板、紧凑面板、存档管理、设置中的自动补给区域。目前文件名对应 0.3.8；更新界面版本时应同步文件名和首页引用。

项目链接正式程序的 WPF 视图源码、主题与图标，使用独立的演示协调器提供固定数值。通过离屏渲染导出，不启动正式助手，不显示窗口，不连接游戏，也不读取个人设置或真实存档。备份条目、路径、状态和角色数值均为演示数据；自动喝水、自动火把、键盘走图在图中开启以展示效果，不代表首次启动默认开启。

这些图片用于说明真实组件的布局与操作入口，不是游戏运行截图，也不能替代功能或实机验证。不要将生成工具加入面向用户的便携发行包。图标许可与署名沿用 [正式程序的声明](../../src/Overlay/Assets/Icons/ATTRIBUTION.md)。
